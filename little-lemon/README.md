# Little Lemon Table Booking Application

This project is the Capstone deliverable for the Meta Front-End Developer Professional Certificate course.

## Features
- **Responsive Navigation & UI Design**: Built with semantic HTML5 elements adhering to Little Lemon branding.
- **Dynamic Reservation Times**: State managed through `useReducer` updating time slots dynamically via date selection.
- **Form Validation & Edge Cases**: Real-time error state checking for guests, dates, and times.
- **Accessibility Standards**: Implements complete ARIA roles, label associations, screen-reader alert blocks, and keyboard focus states.
- **Unit Testing**: Thoroughly tested using React Testing Library and Jest (`App.test.js`).
